# ❌⭕ Tic Tac Toe

A sleek and modern Tic Tac Toe game built with React, Vite, Tailwind CSS, and npm.

## ✨ Highlights

- Modern glassmorphism UI
- Fully responsive design
- Smooth hover animations
- Winner & draw detection
- Clean React state management
- Built with Tailwind CSS

## 🛠 Tech Stack

- React
- Vite
- Tailwind CSS
- npm

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm dev
```

## 📦 Production Build

```bash
npm build
```
