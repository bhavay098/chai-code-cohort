# Cursor Landing Page UI Clone (HTML + CSS)

This project is a **UI clone of the Cursor (cursor.com) landing page**, built using only **Vanilla HTML and CSS**.  
The goal was to recreate the layout, typography, spacing, and overall look as closely as possible.

---

## 🔗 Original Cursor Website
https://cursor.com/

## 🔗 Project Live Link
https://cursor-ui-clone.netlify.app/

---

## ✅ Sections Recreated

The following sections of the Cursor landing page were recreated:

- **Navbar / Header**
- **Hero Section** (Main heading + download button + hero image)
- **Trusted Partners / Logos Section**
- **Features Section** (multiple feature blocks with images)
- **Testimonials Section**
- **Stay on the Frontier Section** (3 feature cards layout)
- **Changelog Section**
- **Recent Highlights Section**
- **Applied Research / Join Us Banner**
- **Final CTA Section** ("Try Cursor now" download button)
- **Footer Section** (multi-column links + bottom bar)

---

## 🎨 Fonts Used

The website uses the Cursor website’s font files:

- `CursorGothic-Regular`
- `CursorGothic-Italic`
- `CursorGothic-Bold`
- `CursorGothic-BoldItalic`

Loaded using `@font-face` in CSS.

---

## 🎨 Colors Used

Main colors used in the project:

- Background: `#14120b`
- Secondary Background: `#1b1913`
- Hover Background: `#1d1b15`
- Primary Text: `#edecec`
- Secondary Text: `#989895`
- Accent / Link Color: `#f54e00`
- Button Background: `#edecec`
- Button Text: `#14120b`

All colors were managed using CSS variables inside `:root`.
