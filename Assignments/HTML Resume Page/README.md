# HTML Resume Page

A simple and clean resume (demo) webpage built using pure HTML.  
This project was created as part of a web development assignment to practice semantic HTML structure, tables, lists, and basic document layout.

## Demo

To run the project locally:

1. Clone the repository
2. Open the project folder
3. Double click on `index.html`
4. The resume page will open in your browser

## Project Features

- Semantic HTML structure
- Header, main, and footer sections
- About, Skills, Experience, Projects, Education, and Contact sections
- Tables for experience and education
- Lists for skills and project details
- Clean and readable layout
- Beginner friendly structure
