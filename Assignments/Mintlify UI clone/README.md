# Mintlify Landing Page Clone 🌿

This project is a **frontend clone** of the Mintlify landing page, created using only **HTML and CSS**.

The purpose of this project was to practice building a real-world UI layout by recreating an existing modern landing page design.

---

## 🔗 Original Mintlify Website
https://www.mintlify.com

## 🔗 Project Live Link


## 📌 Sections Recreated

The following sections of the Mintlify website were recreated in this clone:

- ✅ Navbar (Logo + Navigation links + Buttons)
- ✅ Hero Section (Heading, subheading, email input + CTA button)
- ✅ Hero Image Section
- ✅ Customer Logos Grid Section
- ✅ "Built for the intelligence age" Section (Feature Cards + Videos)
- ✅ Enterprise Section (Heading, features + customer story card)
- ✅ Customer Stories Slider Section (Cards layout)
- ✅ CTA (Call to Action) Section
- ✅ Footer Section (Links, social icons, security badge, status indicator)
